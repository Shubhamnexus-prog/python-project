# 🛠️ Installation & Usage

### Clone Repository

```bash
git clone https://github.com/Shubhamnexus-prog/python-project.git
```

### Navigate to Project Folder

```bash
cd python-project
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

### Run Any Project

Example:

```bash
python text-editor-app/app.py
```
